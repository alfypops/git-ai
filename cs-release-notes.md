Configurable notes_push publication policy and isolated notes_ref; daemon_repo_roots scopes the daemon to listed repositories (trace events, checkpoints and the untraced-commit fixup); Bash edits within the 2 s grace window are recorded and human writes there are never credited to the agent. Linux and Windows binaries are built in CI; the macOS (Apple silicon) binary is signed with a Developer ID and notarized, and each release is published only after all five binaries match its SHA256SUMS. On Windows, git-ai keeps its own state under the home from the environment (USERPROFILE) and resolves `~` in git config includes HOME first, as Git does. The Windows daemon's control and trace pipes are owned by the current user and open to no other account, refuse remote clients and a name another process already holds, and git-ai's own clients connect at identification level and refuse a pipe another account owns. Apache-2.0. Based on upstream git-ai v1.7.5.
